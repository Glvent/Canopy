# Validation record

The animation extension adds two test files and a seventh example. Its executed
compiler/memory-manager matrix, PTY checks, benchmarks and Windows boundary are
recorded separately in [animation validation](animation.md). The
rendering/input release record below describes the earlier six-example baseline.

Final local checks ran on 2026-09-05. This record describes executed checks;
the configured Windows CI jobs have not run in this workspace. Stable parity
remains gated on those jobs. See [parity](../parity.md) for behavior coverage and
known upstream quirks.

Reproduce from the repository root with the selected Nim on `PATH`:

```sh
nim r --mm:arc tools/tester.nim
nim r --mm:arc tools/tester.nim examples
nim r --mm:orc tools/tester.nim
nim r --mm:orc tools/tester.nim examples
```

The runner prints its actual compiler version and memory manager. Each child
compilation uses an explicit matching manager and a separate version/manager
output and cache directory. Project configuration no longer overrides `--mm`.
The minimum-version macOS compiler was bootstrapped from official Nim 2.2.0
source with its bundled C build script. Linux runs used real Linux containers
with writable build directories and a read-only source mount.

Local logs are `build/final-macos-{220,2210}-{arc,orc}.log` and
`build/final-linux-{220,2210}.log`. All eight matrix combinations exited
successfully. Build artifacts and logs are intentionally
not part of the package.

## Native terminal and examples

`test_ansi`, `test_input`, and `test_pty` cover native mode restoration,
partial-init rollback, output errors, cursor queries without losing adjacent
input, resize, fragmented input, escape timeout and EOF on macOS/Linux.
Terminal tests additionally check failed draw/flush/cursor/callback recovery,
unchanged frames, inline insertion and uint64 frame-counter wrapping.

The final macOS binaries were also launched in fresh 80x24 pseudo-terminals:
keyboard with `q` and Ctrl-C, dashboard with Down/`q` and Ctrl-C, and inline
output to completion. All five exited zero and restored native modes and cursor
visibility; fullscreen examples also left the alternate screen. A harness
answered terminal cursor queries and enforced a five-second deadline. macOS's
kernel-owned `PENDIN` normalization was excluded from mode comparison.

The ARC and ORC gallery outputs matched byte-for-byte. Dashboard snapshot and
custom-widget/backend examples ran successfully. The custom backend reported
12 total changed cells across two identical frames, confirming no updates on
the second frame. Gallery/benchmark workloads and recorded timings are in
[benchmarks/README.md](../../benchmarks/README.md).

## Windows boundary

Nim 2.2.0 and 2.2.10, ARC and ORC, successfully generated Windows amd64 C for
`test_windows.nim` and all six examples. Imported Win32 member spellings were
inspected in generated C. This is neither a C compile/link nor a Windows run.
The console tests allocate/open a real console, validate modes and rollback,
and inject a key through `WriteConsoleInputW`; their actual execution remains
the release gate. See [Windows validation](windows.md).

The checked-in workflow configures all 12 OS/version/manager combinations.
No remote workflow result is claimed.
